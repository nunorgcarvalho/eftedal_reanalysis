# Reference values from the 2025 R analysis

Generated by running the 2025 R code (kept outside the repository) unchanged, apart from
restoring the scalar `get_RSS()` that `02_sensitivity_to_weights.R` was written against:

- `nhgri_fits.csv`: the 32 fits behind the NHGRI 2026 poster (8 models x {log, lin} x
  {invSqErr, hybrid}; BOBYQA, bounds [0, 1]). `objective` is the 2025 loss at those
  parameters.
- `nhgri_predictions.csv`: the 2025 `pred_full_model()` at each of those fits, for all 82 rows.
- `nhgri_bs2_cis.csv`: 95% parametric-bootstrap intervals (1000 replicates) from the 2025 run.
- `sensitivity_table.csv`: the 30-row table of the 2025 write-up "Sensitivity of Eftedal
  results to optimization parameters" (02_sensitivity_to_weights.R).
